# AC02 — Transformações Geométricas 2D

⬅️ [[Painel]] · relacionado: [[AC01]]

Resolve 10 exercícios de transformações geométricas com **matrizes homogêneas
3×3** e Matplotlib. Código: `AC02_transformacoes_geometricas/transformacoes.py`.
Relatório: `relatorio/AC02_relatorio.md`.

## Fundamento
Cada ponto vira `[x, y, 1]`; cada transformação é uma matriz 3×3. Composição =
produto ordenado das matrizes `M = M3 @ M2 @ M1`.

| Transformação | Matriz |
|---|---|
| Translação | `[[1,0,tx],[0,1,ty],[0,0,1]]` |
| Escala | `[[sx,0,0],[0,sy,0],[0,0,1]]` |
| Rotação θ | `[[cosθ,−sinθ,0],[sinθ,cosθ,0],[0,0,1]]` |
| Reflexão x / y | escala `(1,−1)` / `(−1,1)` |
| Cisalhamento h | `[[1,k,0],[0,1,0],[0,0,1]]` |
