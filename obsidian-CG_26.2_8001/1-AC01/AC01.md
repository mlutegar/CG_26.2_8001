# AC01 — Áreas da Computação Visual

⬅️ [[Painel]]

Atividade que demonstra as quatro áreas da Computação Visual pelo par
**entrada → saída**, com um script executável por área:

| Área | Entrada → Saída | Script |
|---|---|---|
| Síntese | cena 3D → imagem | `01_sintese_imagens/raytracer.py` |
| Processamento | imagem → imagem | `02_processamento_imagens/processamento.py` |
| Visão | imagem → descrição | `03_visao_computacional/visao.py` |
| Visualização | dados → imagem | `04_visualizacao_computacional/visualizacao.py` |

Relatório: `relatorio/AC01_relatorio.md`. Runner: `executar_tudo.py`.

Relacionado: [[AC02]]
